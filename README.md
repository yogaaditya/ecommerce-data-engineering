# E-commerce Data Engineering Platform
End-to-end data engineering project using SQL Server and Google Cloud Platform (GCP)

## Architecture
SQL Server -> Python ETL -> Google Cloud Storage -> Dataflow -> BigQuery -> Airflow -> Dashboard

## Technology
- SQL Server
- T-SQL
- Python
- Docker
- Google Cloud Storage
- Google BigQuery
- Google Dataflow
- Apache Airflow
- Git
- Github
- Looker Studio
